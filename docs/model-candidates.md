# Кандидаты моделей и стоимость

Сценарий — одна проверка текстового резюме по вакансии без инструментов. Рабочая оценка — 1 200 входных токенов (инструкция и рубрика 250, вакансия 250, резюме 700) и 160 выходных. Лимит — 2 000 входных и 160 выходных. Тарифы без скидки за кеширование, проверены 22 ноября 2026 года.

| Модель | Тариф за вход / выход | Оценка за запрос | Оценка за 1 000 запросов |
| --- | --- | ---: | ---: |
| GPT-4.1 mini | $0,40 / $1,60 за 1 млн токенов | $0,000736 | $0,736 |
| Alice AI LLM Flash, синхронный режим в РФ | 0,10 ₽ / 0,20 ₽ за 1 тыс. токенов, с НДС | 0,152 ₽ | 152 ₽ |
| Qwen3-0.6B локально | Тариф за вызов отсутствует | 0 за API | 0 за API |

Источники ставок и характеристик: [OpenAI](https://developers.openai.com/api/docs/models/gpt-4.1-mini), [Yandex AI Studio](https://aistudio.yandex.ru/ru/docs/ai-studio/pricing), [Qwen](https://huggingface.co/Qwen/Qwen3-0.6B).

Формула — (вход × ставка входа + выход × ставка выхода) / единица тарифа. При потолке 2 000 + 160 токенов один запрос стоит до $0,001056 или 0,232 ₽. Отдельный набор из 200 запросов на оценку добавляет около $0,1472 или 30,40 ₽ по рабочей оценке. Токены измеряются токенизатором кандидата. Цены аренды мощности и труд сопровождения в облачный расчёт не входят.

Локальный запуск оставляет текст резюме на машине. Нужно учитывать веса, KV-кеш и рабочие буферы, а также измерить пропускную способность на целевом железе. Квантизация снижает требования к памяти и меняет точность, поэтому результаты GGUF относятся к конкретному файлу. Локальные затраты можно оценить по ватт-часам за пакет, тарифу и времени эксплуатации.

Если лимит превышен, API не отвечает или модель нарушила формат, оставляем статус «нужна ручная проверка». Поиск по словам может подсветить фрагменты. Подсветка сама по себе не подтверждает навык. Для облачного сравнения на этой стадии используем синтетические данные.
