# Лаба 2. Спайк проверки формата и свидетельств

## Вопрос

Что именно теряет система из-за оболочки ответа, а что из-за неверных цитат?
Проверяем два рискованных допущения: (1) внешняя Markdown-обёртка объясняет
провал свободного вывода и (2) ошибка одной цитаты не должна выбрасывать
свидетельства по соседним критериям.

Данные — те же сохранённые ответы Qwen3-0.6B GGUF на десять синтетических
резюме из [первой лабораторной](lab1.md). Все 30 ответов взяты из её ноутбука.
Новых обращений к модели нет. Сравнение попарное: каждая политика получает
тот же ответ, исходное резюме и человекочитаемую разметку только для подсчёта.
Оцениваем число обработанных ответов и микро-F1 по 30 парам «резюме × критерий».

| Промпт | Политика | Обработано | TP / FP / FN | F1 |
| --- | --- | ---: | ---: | ---: |
| brief | Строгий ответ | 0/10 | 0 / 0 / 16 | 0,000 |
| brief | Снять одну внешнюю Markdown-обёртку | 7/10 | 4 / 2 / 12 | 0,364 |
| brief | Дополнительно оставить только валидные строки | 10/10 | 4 / 2 / 12 | 0,364 |
| evidence | Строгий ответ | 0/10 | 0 / 0 / 16 | 0,000 |
| evidence | Снять одну внешнюю Markdown-обёртку | 3/10 | 3 / 2 / 13 | 0,286 |
| evidence | Дополнительно оставить только валидные строки | 10/10 | 5 / 2 / 11 | 0,435 |
| evidence_schema | Строгий ответ | 5/10 | 4 / 1 / 12 | 0,381 |
| evidence_schema | Снять одну внешнюю Markdown-обёртку | 5/10 | 4 / 1 / 12 | 0,381 |
| evidence_schema | Дополнительно оставить только валидные строки | 10/10 | 4 / 1 / 12 | 0,381 |

«Обработано» означает, что политика вернула карточку, включая карточку без
свидетельств. Валидная строка содержит разрешённый ключ и дословную цитату.
Она может оказаться ошибочным подтверждением по смыслу, что видно по FP.

## Что выяснили и что решили

1. **Гипотеза про формат подтвердилась частично.** Для `evidence` снятие обёртки
   подняло F1 с 0 до 0,286, но семь ответов всё ещё целиком отклоняются.
   В живом контракте используем структурированный вывод провайдера.
   Снятие Markdown здесь диагностический контроль.
2. **Частичная проверка полезна для одного из трёх режимов.** Для `evidence`
   сохраняются ещё два истинных подтверждения при том же числе ложных.
   В `evidence_schema` покрытие карточек выросло, подтверждений не прибавилось.
   В пайплайне изолируем ошибку строки, но не принимаем сломанный верхний
   уровень. Любое непроверенное свидетельство становится вопросом рекрутеру.
3. **Качество модели не доказано.** Максимум F1 0,435 ниже F1 поиска по словам
   0,698. Пилот сохраняет цитирование как проверку источника. Для допуска
   модели нужны независимая разметка и ручная проверка смысла цитат.

Повторить из корня: `python docs/experiments/lab2.py`. Также доступен
[ноутбук](lab2.ipynb), где сохранён результат. Весов и сетевого доступа для
повторного подсчёта не требуется.
