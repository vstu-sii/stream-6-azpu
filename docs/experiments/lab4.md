# Лаба 4. A/B проверки свидетельств

## Что изменилось

В лабе 3 модель принимала чужой опыт, упоминание навыка в документации и
постороннюю инструкцию за свидетельства. Проверили, поможет ли дать ей
выбирать ID короткого фрагмента, а сам текст цитаты брать из исходника.
Вариант A (`quote`) оставляет промпт лабы 3; B (`segment`) возвращает только
ID или null; C (`short`) использует тот же промпт и сокращает контекст
лексическим отбором фрагментов. Запускаем одну Qwen3-4B на [новых синтетических
резюме](lab4-cases.json) с заранее заданными навыками и ID свидетельств.
Использовать этот набор для повторной оценки после доработок можно только как
регрессионный, для финальной оценки нужна ещё одна выборка.

## Результат

| Режим | TP / FP / FN | F1 | Полные совпадения | Средние вход / выход | CPU p50 / p95, с |
| --- | ---: | ---: | ---: | ---: | ---: |
| [quote](lab4-quote.csv) | 9 / 4 / 4 | 0.692 | 3/8 | 317.1 / 62.6 | 7.27 / 29.51 |
| [segment](lab4-segment.csv) | 13 / 4 / 0 | 0.867 | 5/8 | 291.6 / 20.2 | 2.92 / 5.63 |
| [short](lab4-short.csv) | 13 / 5 / 0 | 0.839 | 5/8 | 273.5 / 20.5 | 2.81 / 3.24 |

Поиск по фрагментам оценён отдельно. В C осталось 17 из
27 фрагментов, в них 13 из
13 эталонных пар «критерий, фрагмент». Это покрытие отбора,
а F1 в таблице относится к конечным подтверждениям. Источники — части одного
резюме, внешнего RAG в продукте нет.

Правило выбора пилота: без падения F1 и роста числа ложных подтверждений
относительно A, затем минимум входных и выходных токенов. По нему выбран
**`segment`**. ID позволяет серверу гарантировать происхождение цитаты,
но не гарантирует её смысл. Отрицания и чужой опыт по-прежнему нужно
учитывать в качественном разборе. [Контракт инструмента](../../ml/tools/README.md).

Повторный синтетический запрос в проверке кэша использовал
0 входных и 0 выходных токенов
при том же результате. [Трасса первого и повторного вызовов](lab4-cache.json).
Кэш выключен по умолчанию. [Учёт стоимости](../ml-cost.md).

получены на CPU; у A был холодный старт, отдельная проба кэша добавляла

токенов сопоставляются попарно по одинаковым документам.
