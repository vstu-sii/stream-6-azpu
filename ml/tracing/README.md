# Трассировка модели

Запустите API с `AZPU_TRACE_FILE=/tmp/azpu-trace.local.jsonl`. У каждого
вызова модели есть `assessment_id`, имя модели, версия промпта, задержка
в миллисекундах, число входных и выходных токенов, статус и счётчик
цитат. Ошибка вызова остаётся событием, даже когда ответ ушёл на ручную проверку.

`python -m ml.tracing.view /tmp/azpu-trace.local.jsonl /tmp/azpu-trace.html`
создаёт локальный HTML. Страницу можно открыть обычным браузером. Включите
`AZPU_TRACE_SYNTHETIC_PAYLOADS=1`, если отлаживаете исключительно синтетические
примеры и хотите раскрывать промпты и ответы. По умолчанию эти поля отсутствуют.
Не включайте расширенную трассировку на реальных данных.
