# Инструмент read_segment

Модель выбирает `segment_id` в структурированном ответе. Сервер передаёт
`read_segment(segments, segment_id)` только словарь фрагментов текущего резюме.
У инструмента нет доступа к файлам, внешним адресам и другим запросам.
Успешный результат содержит `segment_id`, `start`, `end` и дословную
`quote`. Неизвестный ID, пустой фрагмент или длина свыше 350 символов дают
`None`.

## Таймаут и деградация

В рабочей ветке валидации инструмент вызывается через
`read_segment_with_timeout` из [evidence.py](evidence.py). Сервер ждёт каждый
результат не более 50 мс через `Future.result(timeout=...)`. Если два
обработчика уже заняты, новый вызов сразу возвращает ошибку таймаута.
Пул ограничен двумя задачами. Запущенный вызов может закончиться после
ответа сервера, а его поздний результат отбрасывается.

На таймауте соответствующее требование получает `needs_review` и
вопрос рекрутеру. Остальные успешно проверенные цитаты остаются в ответе.
В трассу записывается число таких отказов как `evidence_tool_timeouts`.
Ответ с таймаутом не попадает в кэш, поэтому следующий запрос снова
проверит этот фрагмент. Таймаут относится к чтению свидетельства в памяти.
Генерация локальной модели ограничена контекстом и числом токенов.

Проверка через HTTP с намеренной задержкой одного фрагмента:

```sh
python -m unittest discover -s tests -p test_evidence_timeout.py -v
```
