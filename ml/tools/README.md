# Инструмент read_segment

Модель выбирает аргумент `segment_id` в JSON из набора фрагментов запроса.
`read_segment(segments, segment_id)` возвращает объект
`{segment_id, start, end, quote}` или `None`, если ID не принадлежит запросу,
фрагмент пуст или длиннее 350 символов. Внешние адреса, файловые пути и
чужие документы в контракте отсутствуют. Граница доступа обеспечивается
передачей сервером словаря только текущего резюме. Код читает память
синхронно, без I/O; работа ограничена одной операцией поиска и проверкой
строки. При отказе API остаётся доступным и формирует вопрос рекрутеру.
