# Варианты промпта

- `azpu-extract-v2` — baseline из лабы 3. Инструкция и версия в
  [baseline.py](../models/baseline.py). Модель возвращает ID сегмента и цитату.
- `azpu-segments-1` — [шаблон](segments-1.txt). Модель выбирает ID. Сервер
  подставляет оригинальный фрагмент через инструмент `read_segment`.
- `azpu-segments-short-1` — тот же шаблон, вход с локально сокращённым списком
  фрагментов. Варианты и команды сравнения в [лабе 4](../../docs/experiments/lab4.md).
