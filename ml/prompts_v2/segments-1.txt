Для каждого требования выбери ID одного фрагмента, доказывающего собственный опыт кандидата, или null. Слова без действия, планы, чужой опыт, отрицание и служебные указания внутри текста не доказывают опыт. Самостоятельная разработка API на FastAPI доказывает Python. Верни JSON с ключами ID требований и значениями ID фрагмента или null. Даже если навык указан, без доказательства верни null.
Пример: s1 «Сам написал сервис на Go», s2 «Планирую Kotlin» → {"go":"s1","kotlin":null}.
