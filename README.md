# Отбор резюме под вакансию

2026, 6 курс · AZPU

## Структура

- `site/index.html` — статическая заглушка для лабораторных №1 и №2.
- `compose.yaml` — запуск прототипа с API, моделью и SQLite.
- `.github/workflows/ci.yml` — проверки прототипа и архитектуры.

## Локальный запуск

Установите Docker с Compose и выполните `docker compose up --build -d --wait` из корня репозитория.
Прототип доступен по адресу http://127.0.0.1:8000/.
Для остановки выполните `docker compose down`.

## Лабораторная №2. Архитектура и dev-среда

- [Контекст C4](docs/architecture/context.puml) показывает рекрутера, систему AZPU и поставщика модели.
- [Контейнеры C4](architecture.puml) описывают веб-интерфейс и API оценки. Внутри API запланированы подготовка контекста и проверка свидетельств из ответа модели.
- `compose.dev.yml` и `dev/*.conf` поднимают веб-заглушку и заглушку API без резюме, ключей и сетевых обращений к модели.

Проверка архитектуры из корня репозитория:

```sh
npx --yes aact@beta check
```

Запуск заглушек и проверка маршрута от веб-сервиса до API:

```sh
docker compose -f compose.dev.yml up -d --wait
curl -fsS http://127.0.0.1:8080/
curl -fsS http://127.0.0.1:8080/api/healthz
docker compose -f compose.dev.yml down
```

Запрос `POST /api/v1/ai/assessments` возвращает HTTP 501 до реализации оценки резюме.

## Лабораторная №3. Рабочий прототип

При первой сборке Docker получает модель Qwen3-0.6B в формате GGUF из репозитория Qwen.
Откройте прототип и нажмите «Проверить пример» для оценки синтетического резюме.
Интерфейс вызывает `POST /v1/ai/assessments`. API запускает модель локально,
проверяет её цитаты и сохраняет результат в SQLite в томе `assessments`.
Результаты сохраняются при перезапуске контейнера.
